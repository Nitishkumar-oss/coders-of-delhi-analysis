# Coders of Delhi - Data Analysis Project

## 📌 Overview
This project focuses on analyzing data of coders in Delhi to extract meaningful insights using data science techniques.

## 📊 Key Analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualization of trends and patterns

## 📈 Insights
- Distribution of coders based on skills
- Popular technologies used
- Trends in coding community

## 🛠️ Technologies Used
- Pure Python
